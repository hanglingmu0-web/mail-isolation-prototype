# Usage

## Start the environment and read email

Open Hyper-V Manager on Windows, select the email virtual machine, and connect to it. Start it if necessary, sign in to Ubuntu, and open the email application.

Read and compose email inside Ubuntu. Enter credentials directly into the email service's legitimate authentication screen.

## Export a message body

1. Select the message in Thunderbird and save it as an `.eml` file inside Ubuntu.
2. Open the body extraction application from Ubuntu's application list.
3. Select the saved `.eml` file and review the extracted body text.
4. Transfer the body text.
5. Review it in Text Only Gate on Windows.
6. Save it as a new UTF-8 `.txt` file if needed, or discard it.

Original messages and attachments are handled inside Ubuntu. Restoring exported link notation and opening the resulting destination is not part of this workflow.
